# 九九小课堂（jiujiu）

这是已发布应用的独立源码副本。随机出 1–9 的乘法题，朗读题目，识别口头答案；答对后恭喜并出下一题，答错最多重试三次，第三次错误后公布答案。还包括数字键盘、输入框、手动朗读与暂停。

## 启动

需要 Node.js 22 或更高版本、现代浏览器。无第三方依赖，不必执行 npm install。

1. 进入 `jiujiu` 项目文件夹。
2. 在该文件夹打开终端，运行：

```sh
node server.mjs
```

3. 在浏览器打开 `http://127.0.0.1:5173`，点击“开始练习”。需要语音时允许麦克风权限。
4. 用终端的 Ctrl+C 停止服务。

也可以运行 `npm start`。端口被占用时：

```sh
node server.mjs --port 5174
```

服务仅监听本机回环地址，不会向局域网或互联网公开。不要直接双击 `dist/index.html`：页面使用 JavaScript 模块，需要通过本地 HTTP 服务打开。

## 语音与隐私

本地版无需注册或登录。应用不存储录音、答案或练习记录；刷新页面会清空当轮记录。应用本身没有上传或统计代码。语音识别由浏览器提供，可能需要网络并由浏览器的语音服务处理。不同浏览器、操作系统和语言包的支持情况不同，不能保证完全离线语音识别。

只在朗读结束后打开麦克风。没听清、语音服务错误或麦克风权限被拒绝不会扣答题次数。语音不可用时关闭“自动听答案”，用数字键盘继续。

## 测试

```sh
npm test
```

包含 13 项逻辑与模拟语音流程测试。已检查桌面浏览器流程和 390px 手机布局；本机的真实麦克风、扬声器及语音识别需要设备实测。

## 文件

- `dist/`：完整 HTML、CSS、JavaScript 前端源码，无构建步骤。
- `server.mjs`：零第三方依赖的本机静态文件服务器。
- `tests/`：题库、中文数字解析、三次重试和语音状态机测试。
- `package.json`：启动和测试命令。

源码包不含线上站点 ID、Git 历史、密钥、缓存或 node_modules。运行或修改此副本不会改变已发布站点。
