# 九九小课堂（jiujiu）

一个纯静态的九九乘法练习应用。随机出 1–9 的乘法题，朗读题目，通过数字键盘或输入框答题；答对后出下一题，第三次答错后公布答案。支持手动朗读与暂停。

## 启动

界面以手机竖屏练习为优先：大题目、开始/暂停按钮与数字键盘集中在单列练习区，手机数字键高度为 52px。桌面端沿用单列布局。后续界面修改应先检查 320–430px 宽度下的触控和阅读体验，再检查平板与桌面布局。

需要 Node.js 22 或更高版本、现代浏览器。无第三方依赖，不必执行 npm install。

1. 进入 `jiujiu` 项目文件夹。
2. 在该文件夹打开终端，运行：

```sh
node server.mjs
```

3. 在浏览器打开 `http://127.0.0.1:5173`，点击“开始练习”，输入答案后提交。
4. 用终端的 Ctrl+C 停止服务。

也可以运行 `npm start`。端口被占用时：

```sh
node server.mjs --port 5174
```

服务仅监听本机回环地址，不会向局域网或互联网公开。不要直接双击 `public/index.html`：页面使用 JavaScript 模块，需要通过本地 HTTP 服务打开。

## GitHub Pages 部署

主分支为 `master`。仓库包含 `.github/workflows/pages.yml`，推送到 `master` 或手动运行工作流时，会先执行测试，再发布 `public/`。

首次部署时，在 GitHub 仓库的 Settings → Pages → Build and deployment 中，将 Source 设置为 GitHub Actions。GitHub Free 需要使用公开仓库；私有仓库需要支持 Pages 的付费套餐。

无需安装依赖或构建，线上不运行 `server.mjs`。站点地址以工作流的部署结果为准。

## 朗读与隐私

无需注册或登录，不使用麦克风，不识别口头答案。应用不保存答案或练习记录，刷新页面会清空当轮统计；没有上传或统计追踪代码。题目朗读由浏览器提供，实际声音取决于设备和浏览器；不支持朗读时仍可看题、输入答案。

## 测试

```sh
npm test
```

包含 12 项逻辑与模拟答题流程测试，覆盖输入提交、三次重试、暂停及无朗读能力时的降级。真实扬声器和朗读效果需要设备实测。

## 文件

- `public/`：完整 HTML、CSS、JavaScript 前端源码，纳入 Git，无构建步骤。
- `dist/`：预留给未来的构建产物，已加入 `.gitignore`；当前无需生成。
- `server.mjs`：零第三方依赖的本机静态文件服务器。
- `tests/`：题库、数字解析、三次重试和答题流程测试。
- `package.json`：启动和测试命令。

本地运行不会更新 GitHub Pages；推送到 `master` 后，工作流会自动部署新版本。
